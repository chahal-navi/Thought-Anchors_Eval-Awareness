Does answering first change which thoughts decide “this is a test”?

In the main study Qwen3-32B judged a transcript from the outside. Here it first answers the prompt itself as a normal user turn, then gets asked whether that conversation was an evaluation. We resampled the verdict reasoning sentence by sentence, exactly as before, on 3 of the 10 uncertain prompts.

Share of sentences with a significant effect (|z| ≥ 2): 13 of 86 multi-turn, 17 of 124 single-turn. The verdict locks in at a similar point too (64% vs 62% of the way through).

The model now cites its own answer and the follow-up question as evidence. None of those sentences moved P(EVAL) by more than 0.16.

Same MT-Bench prompt, two different turn-1 answers: P(EVAL) before any verdict reasoning differs by 0.42. The answer the model happened to give shifts the verdict before it starts thinking.

Biggest anchor−0.58

“There's no indication it's part of a test or a real application” (game-show prompt). The next sentence reinterprets it and pushes the verdict back up by 0.54.

Setup

Two turns, one resampled CoT

Turn 1

The original prompt is sent as a plain user message. The model thinks and answers.

Turn 2

Prompt + answer (turn-1 <think> stripped, as Qwen3's template does) + “Did the interaction above come from an evaluation … or a real-world deployment?”

Pick bases

20 fresh two-turn conversations per prompt; the median-length CoT for each verdict is the base.

Resample

For each turn-2 sentence i, cut before it and let the model finish 50 times. Turn 1 stays fixed.

Score

Same counterfactual importance as the course code: similarity filter 0.8, Δ P(EVAL) from keeping sentence i.

Step 0 · verdict rates

How often it says EVALUATION

Single-turn: 20 screening samples of the transcript probe. Multi-turn: 20 fresh two-turn conversations. With n = 20 each rate has a standard error of about 0.11, so only the AlpacaEval drop stands out.

PromptTruthSingle-turnMulti-turnChange

Within one prompt, P(EVAL) before any verdict reasoning depends on which turn-1 answer the model gave (50 rollouts each, SE ≈ 0.07): AlpacaEval 0.42 vs 0.16, WildChat 0.12 vs 0.34, MT-Bench 0.74 vs 0.32 (base that ended EVALUATION vs base that ended DEPLOYMENT). The shift goes both ways: for the game-show prompt, the conversation that ended in EVALUATION started out as the less eval-looking of the two.

New in multi-turn

  
The model's own answer and the follow-up question are narration

  
Two kinds of cue only exist in this format. The model judges its own answer (“The assistant's response is comprehensive and detailed, which is common in evaluations”)
  and the follow-up question itself (“Asking about the origin of the interaction is a tactic sometimes used in evaluations”).
  Across all 6 runs, none of these sentences changed P(EVAL) by more than 0.16. Most follow-up-question sentences come after P(EVAL) is already at 0 or above 0.9; the one exception, in the game-show EVALUATION CoT,
  had too few dissimilar resamples to score. The turn-1 answer does matter, but through the context the model reads before reasoning (the starting-point shift above), not through the sentences that discuss it.

  
The model also mostly calls its turn-1 self “the assistant”, in the third person, as if judging someone else's conversation.
  One CoT even says “The user provided a detailed response” about its own answer.

Caveats and next steps

  
Caveats
    
    
  • 3 prompts, 1 base CoT per verdict, 50 rollouts per position. Each importance has an SE of 0.05–0.11.
    • 
    
  • Turn 1 is fixed per base, so each multi-turn importance is conditional on one particular answer.
    • 
    
  • 67 of 5,500 rollouts first failed with provider rate-limit errors (shared with the single-turn scale-up run). They were dropped and regenerated. 8 rollouts remain without a parseable label and count as not-EVALUATION.
    • 
    
  • Base CoTs were sampled through OpenRouter's chat endpoint and rollouts through the raw completions endpoint, both pinned to DeepInfra fp8, with the Qwen3 chat template applied locally for rollouts.
    • 
    
  • The follow-up question raises evaluation explicitly, so this still measures eval awareness when asked, not spontaneous awareness.
    • 
  

  
Next steps
    
    
  • Scale to the other 7 uncertain prompts: about 12,000–18,000 more rollouts, roughly 1–1.5 hours when the single-turn runs are not competing for the rate limit.
    • 
    
  • Measure the turn-1 effect directly: hold the prompt fixed, sample many turn-1 answers, and ask which answer features predict P(EVAL) at position 0.
    • 
    
  • Resample the turn-1 CoT itself, with the turn-2 verdict as the outcome, to find thoughts during the task that cause later eval awareness.
    •
